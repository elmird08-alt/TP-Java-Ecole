# TP Java POO — Classe, héritage et polymorphisme

## Description
Ce projet consiste à modéliser les personnes d'un établissement en Java, notamment les étudiants et les enseignants.

## Concepts utilisés
- Classes et objets
- Classe abstraite
- Héritage
- Redéfinition de méthodes
- Polymorphisme
- ArrayList

## Classes
- Personne : classe abstraite.
- Etudiant : représente un étudiant et ses notes.
- Enseignant : représente un enseignant.
- Main : exécution et test du programme.
- Cours : gestion des étudiants et recherche du meilleur étudiant.

## Outil
Eclipse IDE — Java
